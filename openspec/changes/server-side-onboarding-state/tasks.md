# Tasks: server-side-onboarding-state

> ⚠ **Implementation was completed against an earlier version of these tasks.** Since then, the spec changed:
> (a) login gate sends whitelist-non-empty users to **Dashboard** (never BankSelection);
> (b) re-auth merge is **same-bank-scoped**;
> (c) **UNIQUE(session_id) + idempotency** added;
> (d) **IBAN-only** matching — uid fallback removed;
> (e) legacy import section (10) is new;
> (f) inactive-app gate now routes to **RegistrationReview** (not EmailEntry) — credentials preserved;
> (g) login gate **requires first authorization** — linked-but-never-authorized resumes at the bank list with pre-selection; Dashboard only after `auth_completed`.
> **Re-verify code against the current spec before continuing.**

> Note: single-user by design (VISION.md §2/§4.3) — the new tables carry no `username` column and there is no per-user filtering. Any future multi-user work redesigns this (ownership columns + scoping); out of scope here (D11).
